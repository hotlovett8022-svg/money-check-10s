# 숨은 돈 10초 찾기

로그인·설치 없이 3번만 누르면, 내가 받을 수 있는 **지원금·환급금**을 정부·공공기관 공식 사이트 바로가기로 정리해 주는 무료 정보 페이지입니다.

- 3단계 선택: 연령대 → 가구/상황 → 궁금한 항목
- 결과 카드 8종 (잠든 돈 4 · 생활비 2 · 세금/건강보험 2) + 더 찾아보기 2종
- 모든 링크는 실제 접속(HTTP 200)을 확인한 공식 주소만 사용
- 개인정보(이름·전화·이메일·주소) 수집 없음, 서버 없음 (정적 HTML 1장)
