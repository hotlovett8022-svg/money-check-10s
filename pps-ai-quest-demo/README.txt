《나르미·달이의 2050 AI 조달 마스터》
2026 조달청 AI 게임·콘텐츠 공모전 (AI QUEST) — AI 게임 부문 출품작

■ 실행 방법
1. 압축을 풀고 index.html 파일을 더블클릭하면 바로 실행됩니다. (인터넷 연결 없이 동작)
2. 크롬·엣지·사파리·삼성 인터넷 등 최신 브라우저에서 실행해 주세요.
3. 휴대폰은 세로 화면, PC는 가로 화면에 맞춰 UI가 자동으로 조절됩니다.

■ 조작 방법 (마우스 클릭 / 화면 터치)
- STAGE 1 · AI 서류 스캐너 : [AI 스캔] → 드러난 3개 항목 확인 → [승인] 또는 [반려]
- STAGE 2 · 나라장터 AI 매칭 : 수요기관 요청(혁신·녹색 인증, 예산)에 맞는 제품 카드 선택
- STAGE 3 · 긴급 물자 급파 : 15초 안에 구호물자만 눌러 보급 트럭 5칸 채우기 (엉뚱한 물건은 감점)
- 오른쪽 위 스피커 버튼 : 소리 켜기 / 끄기

■ 구성 파일
- index.html : 게임 전체 (HTML/CSS/JavaScript 한 파일, 외부 라이브러리·CDN 없음)
- assets/narumi.png, assets/dari.png, assets/duo.png :
  조달청 공식 캐릭터 '나르미'·'달이' 이미지(공모전 배포 자료)를 게임용으로 크롭·리사이즈

■ 제작 정보
- 생성형 AI와 협업해 제작한 게임입니다.
- 효과음·배경음악은 Web Audio API로 실시간 합성해 저작권 걱정이 없습니다.
- 글꼴은 Google Fonts(Jua, Noto Sans KR)를 사용하며, 인터넷이 막혀 있어도
  시스템 한글 글꼴로 자동 대체되어 화면이 깨지지 않습니다.

■ 플레이 타임 : 약 1분 ~ 1분 30초 (3개 스테이지)
■ 점수 : STAGE 1·2 각 300점 + STAGE 3 보급 300점 + 남은 시간 보너스
■ 등급 : 900점 이상 S급 수석 조달관 / 600점 이상 A급 베테랑 조달관 / 그 외 B급 새내기 조달관
